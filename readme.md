# Basic Chatbot

A simple rule-based chatbot made with Python.

You type a message and the bot replies with a predefined answer. It keeps running until you say bye.

## How to run

1. Install Python 3
2. Download `chatbot.py`
3. Open a terminal in the folder and run:

```
python chatbot.py
```

## What it understands

| You type          | Bot replies              |
|-------------------|--------------------------|
| hello / hi        | Hi!                      |
| how are you       | I'm fine, thanks!        |
| what is your name | I'm a simple chatbot.    |
| bye               | Goodbye!                 |
| anything else     | Sorry, I don't understand. |

## Example

```
You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks!
You: bye
Bot: Goodbye!
```
